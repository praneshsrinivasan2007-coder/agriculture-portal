# Joke Generator

This is a simple Random Joke Generator that fetches jokes from the icanhazdadjoke API.

How to use

- Open joke-generator/index.html in your browser.
- Click "New Joke" to fetch another random joke.
- Click "Share" to open Twitter with the current joke prefilled.

API

This project uses https://icanhazdadjoke.com/ which returns JSON when the Accept header is set to `application/json`.

Notes

- No build step required, this is a static page.
- You can move the files to your web server or deploy using GitHub Pages.
